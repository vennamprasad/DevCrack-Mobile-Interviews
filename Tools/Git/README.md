## 📖 Available Guide

- **[Advanced Git Interview Guide](./01_git_guide.md)**
  - **1. Debugging History:** `git bisect` (binary search for bug introduction commit), `git blame`, and `git reflog` (recovering deleted branches or detached HEAD commits).
  - **2. Branching & Rebasing:** Interactive rebase (`git rebase -i`), squashing commits, force-with-lease vs force push, cherry-picking.
  - **3. Internals:** The Git object model (Blobs, Trees, Commits, Annotated Tags), SHA-1/SHA-256 content addressing, and `.git/hooks` automation.
  - **4. Large Monorepo Optimization:** Git LFS (Large File Storage), sparse checkouts, and shallow clones.
