## 🧠 Interview Process
1. **Round 1**: Technical Screening (Kotlin/Swift core, Collections, Exception handling, Lifecycle).
2. **Round 2**: Technical Round 2 (MVVM architecture, API integration, background processing with WorkManager/BackgroundTasks).
3. **Round 3**: Scenario-Based Problem Solving (Memory profiling, security hardening, automated unit test coverage).
4. **Round 4**: HR & Managerial Discussion.

---

## 📝 Common Technical Questions
- [ ] **Android WorkManager vs Foreground Service:** When should an enterprise app use WorkManager (deferred, guaranteed execution) versus a Foreground Service?
- [ ] **DataStore Migration:** Migrating legacy SharedPreferences data to Jetpack DataStore safely without user data loss.
- [ ] **Secure Storage & Biometrics:** Storing user session tokens securely using Android Keystore and iOS Keychain Services with biometric gating.
- [ ] **API Resilience & Interceptors:** Implementing an OkHttp authenticator that intercepts 401 Unauthorized responses, refreshes JWT tokens synchronously, and retries the failed request.
