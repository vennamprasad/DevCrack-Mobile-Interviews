# Gojek Mobile Interview Preparation

> **Target:** Senior & Mid-Level Android & iOS Engineers (Super-App Engineering Team)  
> **Tech Stack:** Kotlin, Swift, Dynamic Feature Modules, Clean Architecture, Map APIs, WebSocket Order Tracking

---

## 📌 Company Overview
- **Type**: Southeast Asia Super-App & Tech Giant (GoTo Group)
- **Focus**: Multi-service on-demand ecosystem (GoRide, GoFood, GoSend, GoPay) integrated into a single unified mobile container.
- **Engineering Complexity**: Managing 20+ distinct business verticals inside a single mobile binary with dynamic on-demand feature downloading.

---

## 🧠 Interview Process
1. **Round 1**: Recruiter Screen & Experience Evaluation.
2. **Round 2**: Technical Phone Screen (Object-Oriented Design, Concurrency, Dependency Injection).
3. **Round 3**: Data Structures & Problem Solving (Queues, Graphs, Pathfinding, Concurrency).
4. **Round 4**: Mobile System Design (Design Gojek Multi-Service Super-App Container & Order Dispatch).
5. **Round 5**: Engineering Leadership & Cross-Functional Teamwork.

---

## 📝 Mobile Coding Questions
- [ ] **Dynamic Module Router:** Implement an in-app URL router that dynamically loads on-demand feature modules when a deep link is received.
- [ ] **Multi-Order State Machine:** Model the concurrent lifecycles of a food delivery order and a ride-hailing booking running simultaneously in the app.
- [ ] **Concurrent Driver Polling with Backoff:** Implement an exponential backoff retry mechanism when matching couriers in congested traffic areas.

---

## 🎨 Mobile System Design: Super-App Modular Architecture
- **Dynamic Feature Delivery:** Splitting 20+ services into Play Feature Delivery / On-Demand modules to keep the initial download size under 40MB.
- **Shared Design System (Asphalt):** Enforcing a unified UI design language across hundreds of mobile engineers.
- **Push Notification Action Routing:** Routing transactional notifications to specific sub-feature modules accurately.
