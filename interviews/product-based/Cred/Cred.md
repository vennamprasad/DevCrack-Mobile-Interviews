# CRED Mobile Interview Preparation

> **Target:** Senior & Mid-Level Android & iOS Engineers (Design Engineering & FinTech Team)  
> **Tech Stack:** Kotlin, Jetpack Compose, Swift, SwiftUI, Custom Canvas Graphics, Lottie, Micro-Interactions, Strict Keystore/Keychain Security

---

## 📌 Company Overview
- **Type**: Premium Indian FinTech Unicorn
- **Focus**: High-trust credit card bill payments, neo-banking, peer-to-peer UPI payments, custom neo-brutalist UI animations, gamified rewards.
- **Design Philosophy**: World-renowned for cutting-edge, experimental mobile animations, custom physics engines, and dark-mode aesthetics.

---

## 🧠 Interview Process
1. **Round 1**: Machine Coding / UI Engineering Assignment (Take-home or live 90-min round): Implementing a custom animated UI component (e.g., Credit Score speedometer gauge, interactive swipe-to-pay button).
2. **Round 2**: Assignment Deep Dive & Code Review: Evaluating frame rates (60/120 FPS), memory leaks, and custom canvas rendering.
3. **Round 3**: Data Structures & Problem Solving (Queues, intervals, transaction math, concurrency).
4. **Round 4**: Mobile System Design: Design CRED Coin Rewards Wheel or Real-Time Credit Card Bill Notification System.
5. **Round 5**: Culture & Design Craft: Obsession with user experience, micro-interactions, and visual polish.

---

## 📝 Mobile Coding Questions
- [ ] **Interactive Swipe-to-Pay Slider:** Build a custom gesture-driven slider component in Jetpack Compose / SwiftUI with haptic feedback, spring physics, and anti-glitch release resets.
- [ ] **Credit Score Speedometer Gauge:** Draw a custom circular gradient gauge on a Canvas with smooth bezier needle animation indicating credit rating (300 to 900).
- [ ] **Bill Payment Due Date Sorter:** Group active credit cards by urgency of payment due date, calculating total outstanding dues with multi-currency conversion.

---

## 🎨 Mobile System Design: Design CRED Reward Roulette & Gamification Engine
- **Custom Physics Engine:** Implementing spinning wheels and slot machine reel animations using hardware-accelerated Canvas rendering without frame drops.
- **High-Security Financial Pipeline:** Hardware-backed Keystore/Keychain token storage, SafetyNet/Play Integrity attestation, root/jailbreak detection, and SMS permission alternatives.
- **Offline Payment Verification Queue:** Storing pending bill payments locally and syncing with bank payment gateways with idempotent transaction keys.

---

## 💡 Behavioral & Design Obsession
- At CRED, engineering and design collaborate at the highest pixel level. How do you push back or accommodate designers when an animation impacts battery or frame rate?
- Describe your strategy for diagnosing 120 FPS frame drops on high-refresh-rate OLED displays.
