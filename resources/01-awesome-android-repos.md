# 📱 Awesome Open-Source Android Repositories

> **Curated production-scale Android applications, architectural blueprints, UI showcases, and essential developer libraries.**

---

## 🏛️ 1. Production Architecture Blueprints

| Repository | Tech Stack | Why You Should Study It |
|:---|:---|:---|
| [**android/nowinandroid**](https://github.com/android/nowinandroid) | Jetpack Compose, Kotlin Coroutines & Flow, Hilt, Room, WorkManager, Gradle Convention Plugins | The official Google blueprint for multi-module Clean Architecture, offline-first sync, and design system tokens. |
| [**chrisbanes/tivi**](https://github.com/chrisbanes/tivi) | Compose Multiplatform (KMP), Coroutines, Circuit (Slack), Room, Coin | Real-world TV show tracking app showcasing Kotlin Multiplatform (Android, iOS, Desktop) with Slack's Circuit UDF architecture. |
| [**ZacSweers/CatchUp**](https://github.com/ZacSweers/CatchUp) | Compose, Coroutines, Anvil / Dagger, Room, Moshi, Retrofit | Multi-service content aggregator demonstrating advanced modularization, dynamic feature delivery, and Rx/Coroutine bridges. |
| [**JunkFood02/Seal**](https://github.com/JunkFood02/Seal) | Jetpack Compose, Material 3, Kotlin Coroutines, Room | Modern, beautifully styled video/audio download utility adhering strictly to Material 3 guidelines and dynamic theming. |
| [**Thunder-App/Thunder**](https://github.com/Thunder-App/Thunder) | Jetpack Compose, Room, Hilt, Coil | High-performance open-source Reddit/Lemmy client with smooth gesture navigation, media caching, and local SQLite state. |

## 🛠️ 2. Essential Android Architecture & Quality Libraries

| Library | Author | Purpose |
|:---|:---|:---|
| [**square/leakcanary**](https://github.com/square/leakcanary) | Square | Memory leak detection for Android — inspects object references and heap dumps in debug builds. |
| [**coil-kt/coil**](https://github.com/coil-kt/coil) | Coil-kt | Coroutine-first, lightweight image loader supporting Kotlin Multiplatform, Compose, SVGs, and GIFs. |
| [**slackhq/circuit**](https://github.com/slackhq/circuit) | Slack | Modern, testable, and declarative Kotlin Multiplatform UI framework with unified Presenter/Ui contracts. |
| [**InsertKoinIO/koin**](https://github.com/InsertKoinIO/koin) | Koin IO | Pragmatic, lightweight dependency injection for Kotlin and Kotlin Multiplatform without code generation. |
| [**arrow-kt/arrow**](https://github.com/arrow-kt/arrow) | Arrow | Functional companion to Kotlin's standard library: `Either`, `Option`, typed error handling, and optics. |
| [**JakeWharton/timber**](https://github.com/JakeWharton/timber) | Jake Wharton | Small, extensible utility logging layer on top of Android's `Log` class. |
