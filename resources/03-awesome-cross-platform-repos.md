# 🌉 Awesome Open-Source Cross-Platform Repositories

> **Curated large-scale production codebases for Flutter, React Native, and Kotlin Multiplatform.**

## 💙 1. Top Flutter Production Codebases

| Repository | Tech Stack | Highlights |
|:---|:---|:---|
| [**gskinnerteam/flutter-wonderous-app**](https://github.com/gskinnerteam/flutter-wonderous-app) | Flutter, Provider, Particle Shaders, Impeller | Google's premier showcase app for console-grade 60/120fps animations, custom shader effects, and multi-platform responsive layouts. |
| [**AppFlowy-IO/AppFlowy**](https://github.com/AppFlowy-IO/AppFlowy) | Flutter + Rust FFI, SQLite | Open-source Notion alternative. Masterclass in combining high-performance Rust core logic with Flutter native UI. |
| [**ente-io/ente**](https://github.com/ente-io/ente) | Flutter, End-to-End Encryption, Go / SQLite | 100% encrypted alternative to Google Photos and Apple Photos with local biometrics and streaming uploads. |
| [**invoiceninja/admin-portal**](https://github.com/invoiceninja/admin-portal) | Flutter, Redux, Multi-Platform | Enterprise financial and invoicing platform deployed across Android, iOS, Web, macOS, Windows, and Linux. |
