## 🧠 Interview Process
1. **Round 1**: Technical Screening (Core mobile language principles, OOP, and testing concepts).
2. **Round 2**: Live Coding & Automation Round (Writing automated UI tests or clean MVVM feature implementations).
3. **Round 3**: System Design & Test Strategy (Designing test automation frameworks across physical devices, Firebase Test Lab, and BrowserStack).
4. **Round 4**: Client Delivery & Managerial Round.

---

## 📝 Common Technical Questions
- [ ] **Mobile Test Pyramid:** Strategy for balancing Unit Tests (JUnit, MockK), Integration Tests (Room, Retrofit mocks), and UI/End-to-End Tests (Espresso, Compose Test, XCUITest).
- [ ] **Handling Asynchronous UI in Tests:** Dealing with animations, coroutine delays, and network latency in automated tests using `IdlingResource` or Compose test synchronization.
- [ ] **Flaky Test Elimination:** Root cause analysis and remediation strategies for non-deterministic automated mobile test failures.
- [ ] **CI/CD Mobile Pipelines:** Setting up automated lint checks, build variants, parallel test runs on device farms, and Slack alerts on failure.

---

## 🎨 System Design: Cross-Platform Cloud Mobile Automation Pipeline
- **Test Orchestration Matrix:** Running automated regression suites across 50+ real physical Android and iOS devices on cloud farms.
- **Network Simulation & Chaos Testing:** Injecting network packet loss, latency spikes, and offline states into mobile test suites automatically.
- **Crash & Test Failure Reporting:** Generating HTML test reports with attached failure screenshots, screen video recordings, and Logcat traces.
